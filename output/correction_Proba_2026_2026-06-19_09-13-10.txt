## Questions de cours

**a) Définition d'une probabilité sur un ensemble dénombrable.**

Soit $\Omega$ un ensemble dénombrable non vide. Une probabilité sur $\Omega$ est une application $P : \mathcal{P}(\Omega) \to [0,1]$ vérifiant :
- $P(\Omega) = 1$,
- Pour toute famille dénombrable $(A_n)_{n \geq 1}$ d'événements **deux à deux disjoints** : $P\!\left(\bigsqcup_{n \geq 1} A_n\right) = \sum_{n \geq 1} P(A_n)$.

Équivalent sur $\Omega$ dénombrable : $P$ est entièrement déterminée par $(p_\omega)_{\omega \in \Omega}$ avec $p_\omega \geq 0$ et $\sum_{\omega \in \Omega} p_\omega = 1$.

---

**b) Loi faible des grands nombres.**

Soit $(X_n)_{n \geq 1}$ une suite de variables aléatoires **indépendantes, de même loi**, admettant une espérance finie $m = E[X_1]$. Alors, pour tout $\varepsilon > 0$ :
$$\lim_{n \to +\infty} P\!\left(\left|\frac{X_1 + \cdots + X_n}{n} - m\right| > \varepsilon\right) = 0.$$

---

**c) Fonction génératrice des probabilités d'une loi de Poisson $\mathcal{P}(\lambda)$.**

Pour $|s| \leq 1$ :
$$g_X(s) = E[s^X] = \sum_{k=0}^{+\infty} s^k \, e^{-\lambda} \frac{\lambda^k}{k!} = e^{-\lambda} \sum_{k=0}^{+\infty} \frac{(\lambda s)^k}{k!} = e^{-\lambda} e^{\lambda s} = e^{\lambda(s-1)}.$$

---

**d) État récurrent d'une chaîne de Markov.**

Un état $i \in E$ est dit **récurrent** si, en partant de $i$, la chaîne revient en $i$ avec probabilité $1$, c'est-à-dire :
$$P_i(T_i < +\infty) = 1, \quad \text{où } T_i = \inf\{n \geq 1 : X_n = i\}.$$

## Exercice 1

**a)** $X_1, X_2, X_3$ sont indépendantes de Bernoulli$(\tfrac{1}{2})$, donc $X_1 + X_2 + X_3 \sim \mathcal{B}(3, \tfrac{1}{2})$.

---

**b)** L'événement $\{X_1 + X_2 + X_3 + X_4 = 0\}$ implique $X_1 = X_2 = X_3 = X_4 = 0$, donc $X_1 + X_2 = 0$ sur cet événement. Ainsi :

$$P(X_1 + X_2 = 0 \mid X_1 + X_2 + X_3 + X_4 = 0) = \frac{P(X_1+X_2=0,\, X_3+X_4=0)}{P(X_1+X_2+X_3+X_4=0)}.$$

Par indépendance :
$$= \frac{P(X_1+X_2=0)\,P(X_3+X_4=0)}{P(X_1+X_2+X_3+X_4=0)} = \frac{\frac{1}{4} \cdot \frac{1}{4}}{\frac{1}{16}} = 1.$$

---

**c)** $X_1 X_2 X_3 = 1$ si et seulement si $X_1 = X_2 = X_3 = 1$, ce qui a probabilité $\frac{1}{8}$. Sinon le produit vaut $0$.

Donc $X_1 X_2 X_3 \sim \mathcal{B}\!\left(\tfrac{1}{8}\right)$.

---

**d)** Oui. Posons $V = g(X_1, X_2, X_3, X_4) = \mathbf{1}_{X_1=1,\, X_2=1}$. Alors $V \sim \mathcal{B}(\tfrac{1}{4})$. Cette fonction $g$ est bien définie sur $\{0,1\}^4$ et ne dépend que de $x$ et $y$ : $g(x,y,z,t) = \mathbf{1}_{x=1}\mathbf{1}_{y=1}$.

## Exercice 2

**a)** Soit $X$ de loi géométrique de paramètre $p$ : $P(X = k) = (1-p)^{k-1}p$ pour $k \geq 1$.

$$M_X(s) = E[e^{sX}] = \sum_{k=1}^{+\infty} e^{sk}(1-p)^{k-1}p = pe^s \sum_{k=1}^{+\infty} \left((1-p)e^s\right)^{k-1} = \frac{pe^s}{1-(1-p)e^s},$$

valable pour $s < -\ln(1-p)$.

---

**b)**

**i)** On a $E[S_n] = \frac{n}{p}$ et $\text{Var}(S_n) = \frac{n(1-p)}{p^2}$, donc :
$$W_n = \frac{S_n - \frac{n}{p}}{\sqrt{\frac{n(1-p)}{p^2}}}.$$

Les $X_k$ sont i.i.d., donc par indépendance, $M_{S_n}(s) = \left(M_X(s)\right)^n$. On a $W_n = \frac{S_n - \frac{n}{p}}{\sigma\sqrt{n}}$ avec $\sigma = \frac{\sqrt{1-p}}{p}$, d'où :

$$M_{W_n}(t) = E\!\left[e^{t W_n}\right] = e^{-\frac{n}{\sigma\sqrt{n} \cdot p}\,t}\, M_{S_n}\!\!\left(\frac{t}{\sigma\sqrt{n}}\right) = e^{-\frac{\sqrt{n}}{\sigma p}\,t}\left(\frac{p\,e^{\frac{t}{\sigma\sqrt{n}}}}{1-(1-p)e^{\frac{t}{\sigma\sqrt{n}}}}\right)^n.$$

Puisque $\frac{1}{\sigma p} = \frac{p}{p\sqrt{1-p}} = \frac{1}{\sqrt{1-p}}$, on peut aussi écrire :

$$\boxed{M_{W_n}(t) = e^{-\frac{\sqrt{n}\,t}{\sigma p}}\left(\frac{p\,e^{t/(\sigma\sqrt{n})}}{1-(1-p)e^{t/(\sigma\sqrt{n})}}\right)^n.}$$

---

**ii)** On calcule $\lim_{n\to+\infty} \ln M_{W_n}(t)$ par développement limité. Posons $u = \frac{t}{\sigma\sqrt{n}} \to 0$.

$$\ln M_X(u) = \ln\frac{pe^u}{1-(1-p)e^u}.$$

On développe au voisinage de $u=0$ :
- $e^u = 1 + u + \frac{u^2}{2} + O(u^3)$,
- $1-(1-p)e^u = p - (1-p)u - \frac{(1-p)}{2}u^2 + O(u^3) = p\!\left(1 - \frac{1-p}{p}u - \frac{1-p}{2p}u^2 + O(u^3)\right)$.

Ainsi :
$$\ln M_X(u) = u - \ln\!\left(1 - \frac{1-p}{p}u - \frac{1-p}{2p}u^2 + O(u^3)\right).$$

Soit $v = \frac{1-p}{p}u + \frac{1-p}{2p}u^2 + O(u^3)$. Alors $-\ln(1-v) = v + \frac{v^2}{2} + O(u^3)$.

$$\ln M_X(u) = u + \frac{1-p}{p}u + \frac{1-p}{2p}u^2 + \frac{1}{2}\left(\frac{1-p}{p}\right)^2 u^2 + O(u^3) = \frac{1}{p}u + \frac{(1-p)(2p + 2(1-p))}{2p^2}u^2 + O(u^3).$$

Le coefficient de $u^2$ : $\frac{1-p}{2p}+ \frac{(1-p)^2}{2p^2} = \frac{(1-p)p + (1-p)^2}{2p^2} = \frac{(1-p)}{2p^2}$.

Donc $\ln M_X(u) = \frac{u}{p} + \frac{1-p}{2p^2}u^2 + O(u^3) = \frac{u}{p} + \frac{\sigma^2}{2}u^2 + O(u^3)$.

On en déduit :
$$\ln M_{W_n}(t) = -\frac{t}{\sigma p}\sqrt{n} + n\ln M_X\!\left(\frac{t}{\sigma\sqrt{n}}\right).$$

En substituant $u = \frac{t}{\sigma\sqrt{n}}$ :
$$n\ln M_X(u) = n\left(\frac{t}{\sigma p\sqrt{n}} + \frac{\sigma^2}{2}\frac{t^2}{\sigma^2 n} + O(n^{-3/2})\right) = \frac{\sqrt{n}\,t}{\sigma p} + \frac{t^2}{2} + O(n^{-1/2}).$$

Donc :
$$\ln M_{W_n}(t) = -\frac{\sqrt{n}\,t}{\sigma p} + \frac{\sqrt{n}\,t}{\sigma p} + \frac{t^2}{2} + O(n^{-1/2}) \xrightarrow[n\to+\infty]{} \frac{t^2}{2}.$$

$$\lim_{n \to +\infty} M_{W_n}(t) = e^{t^2/2}.$$

C'est la fonction génératrice des moments de la loi normale standard $\mathcal{N}(0,1)$, ce qui est cohérent avec le théorème central limite.

## Exercice 3

$G(s) = \sum_{k=0}^{+\infty} P(X=k)\,s^k$ est une série entière de rayon infini, donc $G'(s) = \sum_{k=1}^{+\infty} k\,P(X=k)\,s^{k-1}$ est aussi de rayon infini.

$G'$ est une série entière à coefficients $a_k = (k+1)P(X = k+1) \geq 0$.

La somme de ces coefficients vaut :
$$\sum_{k=0}^{+\infty}(k+1)P(X=k+1) = \sum_{j=1}^{+\infty} j\,P(X=j) = E[X] = 3.$$

Posons $\alpha = \frac{1}{E[X]} = \frac{1}{3}$. Alors $\alpha G'(s) = \sum_{k=0}^{+\infty} \frac{(k+1)P(X=k+1)}{3} s^k$.

Les coefficients $q_k = \frac{(k+1)P(X=k+1)}{3}$ vérifient $q_k \geq 0$ et $\sum_{k=0}^{+\infty} q_k = \frac{1}{3}\cdot 3 = 1$. Le rayon de convergence est infini.

Donc $\alpha G' = \frac{1}{3}G'$ est une fonction génératrice des probabilités, avec $\alpha = \frac{1}{3} > 0$.

## Exercice 4

La matrice de transition est :
$$Q = \begin{pmatrix} 0 & 0 & 1 \\ 0 & 1 & 0 \\ \tfrac{1}{2} & \tfrac{1}{2} & 0 \end{pmatrix}$$

où les lignes/colonnes sont indexées par $1, 2, 3$.

**1. Nature des états.**

On cherche les classes de communication :
- Depuis $1$ : $1 \to 3$ (car $Q(1,3)=1$), $3 \to 1$ (car $Q(3,1)=\tfrac{1}{2}$) et $3 \to 2$ (car $Q(3,2)=\tfrac{1}{2}$). Donc $1 \leftrightarrow 3$.
- Depuis $2$ : $Q(2,2)=1$, donc $2$ est absorbant ; $2$ ne communique pas avec $1$ ni $3$.
- Depuis $1$ (ou $3$), on peut atteindre $2$, mais depuis $2$ on ne peut pas revenir en $1$ ou $3$.

Donc les classes de communication sont $\{2\}$ et $\{1,3\}$.

- **État $2$** : classe fermée $\{2\}$, donc état **récurrent** (absorbant).
- **États $1$ et $3$** : la classe $\{1,3\}$ est non fermée (on peut en sortir vers $2$), donc $1$ et $3$ sont **transitoires**.

---

**2. $(Y_n)$ n'est pas une chaîne de Markov.**

Rappel : $Y_n = \phi(X_n)$ avec $\phi(1)=1$, $\phi(2)=\phi(3)=2$.

On montre que la propriété de Markov est violée. Considérons :

$$P(Y_2 = 1 \mid Y_1 = 2, Y_0 = 1) \quad \text{et} \quad P(Y_2 = 1 \mid Y_1 = 2, Y_0 = 2).$$

**Calcul de $P(Y_2=1 \mid Y_1=2, Y_0=1)$ :**

$Y_0=1 \Leftrightarrow X_0=1$. $Y_1=2 \Leftrightarrow X_1 \in \{2,3\}$. Depuis $X_0=1$, on a $X_1=3$ p.s. (car $Q(1,3)=1$), donc $X_1=3$.

$$P(Y_2=1 \mid X_1=3) = P(X_2=1 \mid X_1=3) = Q(3,1) = \tfrac{1}{2}.$$

**Calcul de $P(Y_2=1 \mid Y_1=2, Y_0=2)$ :**

$Y_0=2 \Leftrightarrow X_0 \in \{2,3\}$. Mais $P(X_0=2)=0$ et $P(X_0=3)=\tfrac{1}{2}$, donc conditionnellement à $Y_0=2$, on a $X_0=3$.
Depuis $X_0=3$ : $X_1=1$ avec proba $\tfrac{1}{2}$ (mais $\phi(1)=1 \neq 2$) et $X_1=2$ avec proba $\tfrac{1}{2}$ ($\phi(2)=2$). Donc l'événement $\{Y_1=2, Y_0=2\} = \{X_1=2, X_0=3\}$.

$$P(Y_2=1 \mid X_1=2) = P(X_2=1 \mid X_1=2) = Q(2,1) = 0.$$

Ainsi $P(Y_2=1 \mid Y_1=2, Y_0=1) = \frac{1}{2} \neq 0 = P(Y_2=1 \mid Y_1=2, Y_0=2)$.

La loi conditionnelle de $Y_2$ sachant $Y_1$ dépend de $Y_0$ : $(Y_n)$ **n'est pas une chaîne de Markov**.

## Exercice 5

La matrice de transition est :
$$Q = \begin{pmatrix} 0 & \tfrac{2}{3} & \tfrac{1}{3} & 0 \\ \tfrac{1}{2} & 0 & 0 & \tfrac{1}{2} \\ 1 & 0 & 0 & 0 \\ \tfrac{1}{4} & \tfrac{1}{4} & \tfrac{1}{4} & \tfrac{1}{4} \end{pmatrix}$$

**1. Nature des états.**

On analyse les transitions :
- $1 \to 2, 3$ ; $2 \to 1, 4$ ; $3 \to 1$ ; $4 \to 1,2,3,4$.
- $1 \to 3 \to 1$ (cycle), $1 \to 2 \to 1$ (cycle), $1 \to 2 \to 4 \to 1$ (cycle).
- $4 \to 4$ (direct), $4 \to 1 \to 2 \to 4$ (cycle).

Tous les états communiquent entre eux (on vérifie que depuis n'importe quel état on peut atteindre n'importe quel autre) : la chaîne est **irréductible**.

Une chaîne de Markov irréductible sur un espace d'états fini est **récurrente**. Tous les états sont donc **récurrents**.

On vérifie que la chaîne est **apériodique** : $Q(4,4) = \tfrac{1}{4} > 0$ donc l'état $4$ a période $1$, et par irréductibilité tous les états ont période $1$.

Tous les états sont **récurrents positifs apériodiques**.

---

**2. Loi stationnaire.**

On résout $\pi Q = \pi$ avec $\pi_1+\pi_2+\pi_3+\pi_4=1$ et $\pi_i \geq 0$.

Le système $\pi Q = \pi$ donne :

$$\pi_1 = \tfrac{1}{2}\pi_2 + \pi_3 + \tfrac{1}{4}\pi_4$$
$$\pi_2 = \tfrac{2}{3}\pi_1 + \tfrac{1}{4}\pi_4$$
$$\pi_3 = \tfrac{1}{3}\pi_1 + \tfrac{1}{4}\pi_4$$
$$\pi_4 = \tfrac{1}{2}\pi_2 + \tfrac{1}{4}\pi_4$$

De l'équation (4) : $\tfrac{3}{4}\pi_4 = \tfrac{1}{2}\pi_2$, donc $\pi_4 = \tfrac{2}{3}\pi_2$.

De l'équation (2) : $\pi_2 = \tfrac{2}{3}\pi_1 + \tfrac{1}{4}\cdot\tfrac{2}{3}\pi_2 = \tfrac{2}{3}\pi_1 + \tfrac{1}{6}\pi_2$, donc $\tfrac{5}{6}\pi_2 = \tfrac{2}{3}\pi_1$, soit $\pi_2 = \tfrac{4}{5}\pi_1$.

Alors $\pi_4 = \tfrac{2}{3}\cdot\tfrac{4}{5}\pi_1 = \tfrac{8}{15}\pi_1$.

De l'équation (3) : $\pi_3 = \tfrac{1}{3}\pi_1 + \tfrac{1}{4}\cdot\tfrac{8}{15}\pi_1 = \tfrac{1}{3}\pi_1 + \tfrac{2}{15}\pi_1 = \frac{5+2}{15}\pi_1 = \tfrac{7}{15}\pi_1$.

Normalisation : $\pi_1\!\left(1 + \tfrac{4}{5} + \tfrac{7}{15} + \tfrac{8}{15}\right) = 1$.

$$1 + \frac{4}{5} + \frac{7}{15} + \frac{8}{15} = \frac{15 + 12 + 7 + 8}{15} = \frac{42}{15} = \frac{14}{5}.$$

Donc $\pi_1 = \dfrac{5}{14}$, puis :
$$\pi_2 = \frac{4}{5}\cdot\frac{5}{14} = \frac{4}{14} = \frac{2}{7}, \quad \pi_3 = \frac{7}{15}\cdot\frac{5}{14} = \frac{1}{6}, \quad \pi_4 = \frac{8}{15}\cdot\frac{5}{14} = \frac{4}{21}.$$

**Vérification :** $\frac{5}{14}+\frac{2}{7}+\frac{1}{6}+\frac{4}{21} = \frac{5}{14}+\frac{4}{14}+\frac{1}{6}+\frac{4}{21}$.

Commun dénominateur $42$ : $\frac{15}{42}+\frac{12}{42}+\frac{7}{42}+\frac{8}{42} = \frac{42}{42}=1$. ✓

La loi stationnaire est :
$$\pi = \left(\frac{5}{14},\, \frac{2}{7},\, \frac{1}{6},\, \frac{4}{21}\right).$$

---

**3. Temps moyen de retour.**

Pour une chaîne irréductible récurrente positive, $E_x(S_x) = \dfrac{1}{\pi_x}$ pour tout $x \in E$.

$$E_1(S_1) = \frac{1}{\pi_1} = \frac{14}{5}, \quad E_2(S_2) = \frac{1}{\pi_2} = \frac{7}{2}, \quad E_3(S_3) = \frac{1}{\pi_3} = 6, \quad E_4(S_4) = \frac{1}{\pi_4} = \frac{21}{4}.$$
