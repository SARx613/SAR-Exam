## Questions de cours

**a) Définition d'une probabilité sur un ensemble dénombrable non vide $\Omega$**

Une probabilité sur $\Omega$ dénombrable non vide est une application $P : \mathcal{P}(\Omega) \to [0,1]$ telle que :
- $P(\Omega) = 1$,
- Pour toute famille dénombrable d'événements deux à deux disjoints $(A_n)_{n \geq 1}$, $P\!\left(\bigcup_{n \geq 1} A_n\right) = \sum_{n \geq 1} P(A_n)$.

**b) Inégalités de Markov et de Bienaymé-Tchebychev**

**Markov :** Soit $X$ une variable aléatoire positive (ou nulle) d'espérance finie. Pour tout $a > 0$,
$$P(X \geq a) \leq \frac{E(X)}{a}.$$

**Bienaymé-Tchebychev :** Soit $X$ une variable aléatoire de carré intégrable, d'espérance $\mu$ et de variance $\sigma^2$. Pour tout $\varepsilon > 0$,
$$P(|X - \mu| \geq \varepsilon) \leq \frac{\sigma^2}{\varepsilon^2}.$$

**c) Fonction génératrice des probabilités d'une loi géométrique de paramètre $p$**

On prend la convention $P(X = k) = (1-p)^{k-1}p$ pour $k \geq 1$. Alors :
$$g_X(s) = E(s^X) = \sum_{k=1}^{+\infty} s^k (1-p)^{k-1} p = \frac{ps}{1-(1-p)s}, \quad |s| < \frac{1}{1-p}.$$

**d) État transient d'une chaîne de Markov**

Soit $(X_n)_{n \geq 0}$ une chaîne de Markov sur $E$ dénombrable. Un état $i \in E$ est dit **transient** si
$$P_i\!\left(\exists\, n \geq 1,\ X_n = i\right) < 1,$$
c'est-à-dire si la probabilité de retour en $i$ en partant de $i$ est strictement inférieure à $1$.

## Exercice 1

Les $X_i$ sont i.i.d. de loi $\mathcal{B}(1, \frac{1}{3})$.

**a)** Par stabilité de la loi binomiale, $X_1 + X_2 + X_3 + X_4 \sim \mathcal{B}(4, \frac{1}{3})$.

**b)** On calcule $P(X_1 + X_2 = 1 \mid X_1 + X_2 + X_3 + X_4 = 3)$.

Posons $S = X_1 + X_2$ et $T = X_3 + X_4$, indépendantes avec $S \sim \mathcal{B}(2, \frac{1}{3})$ et $T \sim \mathcal{B}(2, \frac{1}{3})$.

$$P(S = 1,\ S + T = 3) = P(S=1,\ T=2) = P(S=1)P(T=2).$$

$$P(S=1) = \binom{2}{1}\frac{1}{3}\cdot\frac{2}{3} = \frac{4}{9}, \quad P(T=2) = \frac{1}{9}, \quad P(S+T=3) = \binom{4}{3}\left(\frac{1}{3}\right)^3\!\left(\frac{2}{3}\right) = \frac{8}{81}.$$

$$P(X_1+X_2=1 \mid X_1+X_2+X_3+X_4=3) = \frac{\frac{4}{9}\cdot\frac{1}{9}}{\frac{8}{81}} = \frac{\frac{4}{81}}{\frac{8}{81}} = \frac{1}{2}.$$

**c)** Le produit $X_1 X_2 X_3 X_4$ vaut $1$ si et seulement si tous les $X_i$ valent $1$, sinon il vaut $0$. Donc $X_1 X_2 X_3 X_4 \sim \mathcal{B}\!\left(1,\, \left(\frac{1}{3}\right)^4\right) = \mathcal{B}\!\left(1, \frac{1}{81}\right)$.

**d)** On cherche $g : \{0,1\}^4 \to \{0,1\}$ telle que $V = g(X_1, X_2, X_3, X_4)$ vérifie $P(V=1) = \frac{1}{2}$.

Les $(X_1, X_2, X_3, X_4)$ prennent $2^4 = 16$ valeurs dans $\{0,1\}^4$, chacune avec une probabilité de la forme $\left(\frac{1}{3}\right)^k \left(\frac{2}{3}\right)^{4-k}$ pour $k \in \{0,1,2,3,4\}$. Ces probabilités sont des fractions de dénominateur $3^4 = 81$, donc $P(V=1)$ est nécessairement un multiple entier de $\frac{1}{81}$. Or $\frac{1}{2}$ n'est pas un multiple entier de $\frac{1}{81}$ (car $81$ est impair). **Une telle fonction $g$ n'existe donc pas.**

## Exercice 2

**a)** Pour $X \sim \mathcal{P}(\lambda)$ :
$$M_X(s) = E(e^{sX}) = \sum_{k=0}^{+\infty} e^{sk} \frac{\lambda^k e^{-\lambda}}{k!} = e^{-\lambda} \sum_{k=0}^{+\infty} \frac{(\lambda e^s)^k}{k!} = e^{-\lambda} e^{\lambda e^s} = e^{\lambda(e^s - 1)}.$$

**b)**

**i)** Les $X_k$ sont i.i.d. de loi $\mathcal{P}(\lambda)$, donc $E(S_n) = n\lambda$ et $\text{Var}(S_n) = n\lambda$.

$$W_n = \frac{S_n - n\lambda}{\sqrt{n\lambda}}.$$

Par indépendance, $M_{S_n}(s) = \left(e^{\lambda(e^s-1)}\right)^n = e^{n\lambda(e^s-1)}$.

$$M_{W_n}(t) = E\!\left(e^{t W_n}\right) = E\!\left(e^{\frac{t}{\sqrt{n\lambda}} S_n - t\sqrt{n\lambda}}\right) = e^{-t\sqrt{n\lambda}}\, M_{S_n}\!\left(\frac{t}{\sqrt{n\lambda}}\right) = e^{-t\sqrt{n\lambda}}\, e^{n\lambda\left(e^{t/\sqrt{n\lambda}}-1\right)}.$$

$$\boxed{M_{W_n}(t) = \exp\!\left(n\lambda\!\left(e^{t/\sqrt{n\lambda}} - 1\right) - t\sqrt{n\lambda}\right).}$$

**ii)** On développe l'exposant quand $n \to +\infty$. En posant $u = \frac{t}{\sqrt{n\lambda}} \to 0$ :

$$e^u - 1 = u + \frac{u^2}{2} + O(u^3),$$

$$n\lambda\!\left(e^{t/\sqrt{n\lambda}}-1\right) - t\sqrt{n\lambda} = n\lambda\left(\frac{t}{\sqrt{n\lambda}} + \frac{t^2}{2n\lambda} + O(n^{-3/2})\right) - t\sqrt{n\lambda} = t\sqrt{n\lambda} + \frac{t^2}{2} + O(n^{-1/2}) - t\sqrt{n\lambda}.$$

L'exposant tend donc vers $\frac{t^2}{2}$, et :

$$\lim_{n \to +\infty} M_{W_n}(t) = e^{t^2/2}, \quad \forall t \in \mathbb{R}.$$

C'est la fonction génératrice des moments de la loi normale $\mathcal{N}(0,1)$, ce qui est cohérent avec le théorème central limite.

## Exercice 3

Soit $X$ à valeurs dans $\mathbb{N}$ avec $E(X) = 1$ et $G(s) = \sum_{k=0}^{+\infty} P(X=k)\, s^k$ de rayon de convergence infini.

On a $G'(s) = \sum_{k=1}^{+\infty} k\, P(X=k)\, s^{k-1} = \sum_{k=0}^{+\infty} (k+1) P(X = k+1)\, s^k$.

Posons $q_k = (k+1)P(X = k+1)$ pour $k \geq 0$. On doit vérifier que $(q_k)$ est une suite de probabilités sur $\mathbb{N}$, i.e. $q_k \geq 0$ et $\sum_{k=0}^{+\infty} q_k = 1$.

- **Positivité :** $q_k = (k+1)P(X=k+1) \geq 0$ pour tout $k \geq 0$. ✓

- **Somme :** $\sum_{k=0}^{+\infty} q_k = \sum_{k=0}^{+\infty} (k+1)P(X=k+1) = \sum_{j=1}^{+\infty} j\, P(X=j) = E(X) = 1$. ✓

(L'échange somme/dérivée est licite car le rayon de convergence est infini, donc en particulier la série converge normalement sur tout compact.)

Ainsi $G'$ est la fonction génératrice des probabilités de la variable aléatoire $Y$ à valeurs dans $\mathbb{N}$ définie par $P(Y = k) = (k+1)P(X = k+1)$.

## Exercice 4

$E = \{1,2\}$, $F = \{Y_n,\ n \geq 0\} = \{2\cdot 1 + 1,\ 2\cdot 2 + 1\} = \{3, 5\}$.

La fonction $\varphi : i \mapsto 2i+1$ est une bijection de $E$ vers $F$, d'inverse $\varphi^{-1}(j) = \frac{j-1}{2}$.

Soit $P = (p_{ij})_{i,j \in \{1,2\}}$ la matrice de transition de $(X_n)$. Pour tous $j_0, \ldots, j_n, j_{n+1} \in F$ :

$$P(Y_{n+1} = j_{n+1} \mid Y_n = j_n, \ldots, Y_0 = j_0) = P(X_{n+1} = \varphi^{-1}(j_{n+1}) \mid X_n = \varphi^{-1}(j_n), \ldots, X_0 = \varphi^{-1}(j_0)).$$

Par la propriété de Markov de $(X_n)$, ceci vaut :

$$P(X_{n+1} = \varphi^{-1}(j_{n+1}) \mid X_n = \varphi^{-1}(j_n)) = p_{\varphi^{-1}(j_n),\, \varphi^{-1}(j_{n+1})}.$$

Ce terme ne dépend que de $j_n$ et $j_{n+1}$. Donc $(Y_n)$ est une chaîne de Markov sur $F = \{3, 5\}$, avec matrice de transition $Q = (q_{j,j'})_{j,j' \in \{3,5\}}$ définie par :

$$q_{j,j'} = p_{\frac{j-1}{2},\, \frac{j'-1}{2}}.$$

Autrement dit, la matrice de transition de $(Y_n)$ dans la base $(3, 5)$ est identique à celle de $(X_n)$ dans la base $(1,2)$ :

$$Q = \begin{pmatrix} p_{11} & p_{12} \\ p_{21} & p_{22} \end{pmatrix}.$$

## Exercice 5

La matrice de transition est :
$$Q = \begin{pmatrix} 0 & 1/2 & 1/2 & 0 \\ 1/2 & 0 & 0 & 1/2 \\ 1 & 0 & 0 & 0 \\ 1/3 & 1/3 & 1/6 & 1/6 \end{pmatrix}$$

### 1. Nature des états

**Communication entre les états.** On vérifie :

- $1 \to 2$ (via $q_{12} = 1/2$) et $2 \to 1$ (via $q_{21} = 1/2$) : $1 \leftrightarrow 2$.
- $1 \to 3$ (via $q_{13} = 1/2$) et $3 \to 1$ (via $q_{31} = 1$) : $1 \leftrightarrow 3$.
- $2 \to 4$ (via $q_{24} = 1/2$) et $4 \to 2$ (via $q_{42} = 1/3$) : $2 \leftrightarrow 4$.

Donc tous les états communiquent : la chaîne est **irréductible**.

**Récurrence.** L'espace d'états $E = \{1,2,3,4\}$ est **fini** et la chaîne est irréductible, donc tous les états sont **récurrents positifs**.

### 2. Loi stationnaire

On résout $\pi Q = \pi$ avec $\pi_1 + \pi_2 + \pi_3 + \pi_4 = 1$.

Le système $\pi Q = \pi$ donne :

$$\pi_1 = \frac{1}{2}\pi_2 + \pi_3 + \frac{1}{3}\pi_4$$

$$\pi_2 = \frac{1}{2}\pi_1 + \frac{1}{3}\pi_4$$

$$\pi_3 = \frac{1}{2}\pi_1 + \frac{1}{6}\pi_4$$

$$\pi_4 = \frac{1}{2}\pi_2 + \frac{1}{6}\pi_4$$

De la 4ème équation : $\frac{5}{6}\pi_4 = \frac{1}{2}\pi_2$, donc $\pi_4 = \frac{3}{5}\pi_2$.

De la 2ème équation : $\pi_2 = \frac{1}{2}\pi_1 + \frac{1}{3} \cdot \frac{3}{5}\pi_2 = \frac{1}{2}\pi_1 + \frac{1}{5}\pi_2$, donc $\frac{4}{5}\pi_2 = \frac{1}{2}\pi_1$, soit $\pi_1 = \frac{8}{5}\pi_2$.

De la 3ème équation : $\pi_3 = \frac{1}{2} \cdot \frac{8}{5}\pi_2 + \frac{1}{6} \cdot \frac{3}{5}\pi_2 = \frac{4}{5}\pi_2 + \frac{1}{10}\pi_2 = \frac{9}{10}\pi_2$.

Normalisation : $\frac{8}{5}\pi_2 + \pi_2 + \frac{9}{10}\pi_2 + \frac{3}{5}\pi_2 = 1$.

$$\pi_2\!\left(\frac{16}{10} + \frac{10}{10} + \frac{9}{10} + \frac{6}{10}\right) = \frac{41}{10}\pi_2 = 1 \implies \pi_2 = \frac{10}{41}.$$

Ainsi :

$$\pi_1 = \frac{16}{41},\quad \pi_2 = \frac{10}{41},\quad \pi_3 = \frac{9}{41},\quad \pi_4 = \frac{6}{41}.$$

**Vérification (équation 1) :** $\frac{1}{2}\cdot\frac{10}{41} + \frac{9}{41} + \frac{1}{3}\cdot\frac{6}{41} = \frac{5}{41} + \frac{9}{41} + \frac{2}{41} = \frac{16}{41} = \pi_1$. ✓

La loi stationnaire est donc :
$$\pi = \left(\frac{16}{41},\ \frac{10}{41},\ \frac{9}{41},\ \frac{6}{41}\right).$$

### 3. Temps moyen de retour

La chaîne étant irréductible et récurrente positive, par le théorème ergodique :

$$E_x(S_x) = \frac{1}{\pi_x}.$$

$$E_1(S_1) = \frac{41}{16}, \quad E_2(S_2) = \frac{41}{10}, \quad E_3(S_3) = \frac{41}{9}, \quad E_4(S_4) = \frac{41}{6}.$$
